# AI Health Check Frontend

Next.js MVP shell for founder-facing AI assurance diagnostics.

- Next.js
- TypeScript
- Tailwind
- shadcn-style local primitives
- Recharts
- Framer Motion-ready dependency

Pages:

- `/dashboard`
- `/evaluate`
- `/reports`
- `/taxonomy`
- `/benchmarks`

Run:

```powershell
cd frontend
npm install
npm run dev
```
