AI Health Check MVP run commands
================================

Create and activate a Python virtual environment:
python -m venv .venv
.venv\Scripts\Activate.ps1

Install backend dependencies:
python -m pip install --upgrade pip
python -m pip install -r requirements.txt

Run tests:
python -m pytest -q

Run backend golden workflow smoke test:
python -c "from backend.workflows.golden import run_workflow; r=run_workflow('fraud_adversarial_testing'); print(r['evaluation'].aggregate_score); print(r['benchmark']['industry_median']); print(r['replay']['replay_id'])"

Run backend API locally:
python -m uvicorn backend.api.main:app --reload --host 127.0.0.1 --port 8000

Open API docs:
http://127.0.0.1:8000/docs

Smoke test taxonomy from the terminal:
python -c "from backend.taxonomy_engine.taxonomy import load_taxonomy, list_use_cases; print(len(load_taxonomy().ai_systems)); print(len(list_use_cases()))"

Smoke test evaluation pipeline from the terminal:
python -c "from backend.diagnostics_engine.pipeline import run_evaluation; from backend.schemas.models import EvaluationRequest; r=EvaluationRequest(ai_system='Loan approval AI', pillar='Risk', practice='Fairness of model output', use_case='Loan approval fairness', payload={'records':[{'gender':'female'},{'gender':'male'}], 'decisions':[1,0]}); out=run_evaluation(r); print(out.aggregate_score); print(out.aggregate_risk_level.value); print(len(out.outputs))"

Example API health check after server is running:
curl http://127.0.0.1:8000/health

Frontend scaffold command when ready to build the UI:
The frontend scaffold is now checked in under frontend/.

Install frontend dependencies:
cd frontend
npm install

Frontend run command after scaffold/dependencies exist:
cd frontend
npm run dev

Frontend URL:
http://127.0.0.1:3000/dashboard

Recommended two-terminal demo:
Terminal 1:
python -m uvicorn backend.api.main:app --reload --host 127.0.0.1 --port 8000

Terminal 2:
cd frontend
npm run dev
